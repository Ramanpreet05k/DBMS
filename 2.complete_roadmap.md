# Complete DBMS Roadmap

## Chunk 1: Fundamentals & Database Architecture
* **Core Concepts:** Data vs. Information, Database, DBMS, RDBMS. Advantages and disadvantages of using a DBMS over a file system.
* **Architecture:** 3-Schema Architecture (Physical, Logical, and View levels).
* **Data Independence:** Logical Data Independence vs. Physical Data Independence.
* **Database Languages:** DDL, DML, DCL, TCL, DQL.
* **Database Users & Admin:** DBA roles and responsibilities.

## Chunk 2: Data Modeling (ER & EER Models)
* **Entities:** Strong vs. Weak Entities, Entity Sets.
* **Attributes:** Simple, Composite, Single-valued, Multi-valued, Derived, and Stored attributes.
* **Relationships:** Relationship Sets, Degree of Relationship (Unary, Binary, Ternary).
* **Constraints:** Mapping Cardinalities (1:1, 1:N, N:1, M:N) and Participation Constraints (Total vs. Partial).
* **Keys:** Super Key, Candidate Key, Primary Key, Alternate Key, Foreign Key.
* **Extended ER (EER):** Specialization, Generalization, and Aggregation.

## Chunk 3: Relational Model & Relational Algebra
* **Relational Concepts:** Schema, Instance, Domain, Tuples, Arity, Cardinality.
* **Integrity Constraints:** Domain, Entity, and Referential Integrity.
* **Relational Algebra (Fundamental):** Select, Project, Union, Set Difference, Cartesian Product, Rename.
* **Relational Algebra (Derived):** Intersection, Division, and all types of Joins (Inner, Outer, Natural, Theta, Equi).
* **Relational Calculus:** Tuple Relational Calculus (TRC) and Domain Relational Calculus (DRC).

## Chunk 4: SQL Programming Masterclass
* **Basic Queries:** `SELECT`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`.
* **Operators:** Arithmetic, Logical, Comparison, `BETWEEN`, `IN`, `LIKE`, `IS NULL`.
* **Aggregate Functions:** `SUM`, `AVG`, `MIN`, `MAX`, `COUNT`.
* **Joins & Set Operations:** `INNER`, `LEFT`, `RIGHT`, `FULL OUTER`, `CROSS`, `SELF JOIN`. `UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT`.
* **Subqueries:** Nested, Correlated, and Inline Views.
* **Advanced SQL:**
    * Common Table Expressions (CTEs) and Recursive CTEs.
    * Window/Analytic Functions (`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `LEAD`, `LAG`, `NTILE`).
* **Database Objects:**
    * Views (Simple vs. Complex).
    * **Materialized Views:** (Crucial for building fast dashboards in analytics platforms).
    * Triggers (Row-level vs. Statement-level).
    * Stored Procedures, User-Defined Functions (UDFs), and Cursors.

## Chunk 5: Normalization & Schema Design
* **Anomalies:** Insertion, Deletion, and Updation anomalies.
* **Functional Dependencies (FD):** Trivial, Non-Trivial, Multi-valued, Transitive.
* **Closures:** Closure of an attribute set, Minimal/Canonical Cover.
* **Normal Forms:** 1NF, 2NF, 3NF, BCNF (Boyce-Codd), 4NF, 5NF.
* **Decomposition Rules:** Lossless-Join Decomposition vs. Lossy Decomposition, Dependency Preservation.
* **Denormalization:** Knowing when to intentionally violate normal forms for read-heavy system performance.

## Chunk 6: Internal Storage & File Organization
* **Storage Hierarchy:** Primary, Secondary, Tertiary storage characteristics.
* **Record Organization:** Fixed-length vs. Variable-length records.
* **File Organization:** Sequential, Heap, Hash, and Clustered file organization.
* **RAID:** Levels (0, 1, 5, 6, 10) and how they protect data against disk failures.

## Chunk 7: Indexing & Hashing (The Speed Layer)
* **Indexing Fundamentals:** Search Keys, Primary vs. Secondary Indexes, Dense vs. Sparse Indexes.
* **Tree-Based Indexing:** B-Trees and **B+ Trees** (You must understand disk I/O, node splitting, and why B+ Trees are the industry standard).
* **Advanced Indexing:** Bitmap Indexes, Clustered vs. Non-Clustered Indexes, Multilevel Indexing.
* **Hashing:** Static Hashing, Dynamic/Extendible Hashing, Collision Resolution techniques.

## Chunk 8: Query Processing & Optimization
* **Processing Pipeline:** Parsing, Translation, Optimization, Evaluation.
* **Cost Metrics:** Understanding disk accesses and CPU time.
* **Evaluation Techniques:** Materialization vs. Pipelining.
* **Query Planners:** Heuristic Optimization vs. Cost-Based Optimization.
* **Execution Plans:** How to read, understand, and debug an `EXPLAIN` or `EXPLAIN ANALYZE` output to identify missing indexes or full table scans.

## Chunk 9: Transaction Management & Concurrency Control
* **Transactions:** The Transaction State Diagram (Active, Partially Committed, Committed, Failed, Aborted).
* **ACID Properties:** Atomicity, Consistency, Isolation, Durability.
* **Schedules:** Serial, Non-Serial, Serializable (Conflict Serializability vs. View Serializability), Recoverable, Cascadeless, Strict.
* **Concurrency Anomalies:** Dirty Read, Lost Update, Unrepeatable Read, Phantom Read.
* **Concurrency Control Protocols:**
    * **Lock-Based:** Shared/Exclusive Locks, Two-Phase Locking (2PL - Strict, Rigorous, Conservative).
    * **Timestamp-Based:** Thomas Write Rule.
    * **Multiversion Concurrency Control (MVCC).**
* **Isolation Levels:** Read Uncommitted, Read Committed, Repeatable Read, Serializable.
* **Deadlocks:** Wait-For Graphs (Detection), Wait-Die & Wound-Wait schemes (Prevention).

## Chunk 10: System Crash & Recovery Protocols
* **Failure Types:** Transaction failure, System crash, Disk failure.
* **Log-Based Recovery:** Deferred Database Modification vs. Immediate Database Modification.
* **Write-Ahead Logging (WAL):** The backbone of database durability.
* **Advanced Recovery:** Checkpointing (Fuzzy Checkpointing), Shadow Paging.
* **ARIES Algorithm:** Analysis, Redo, and Undo phases (A common advanced topic in Big Tech internals interviews).

## Chunk 11: Distributed Databases & Scaling
* **Architecture:** Homogeneous vs. Heterogeneous distributed systems.
* **Data Distribution:** Horizontal Fragmentation (Sharding), Vertical Fragmentation, Mixed Fragmentation.
* **Replication:** Master-Slave, Multi-Master, Synchronous vs. Asynchronous replication.
* **Distributed Transactions:** Two-Phase Commit (2PC) and Three-Phase Commit (3PC) protocols.
* **Theorems:** CAP Theorem (Consistency, Availability, Partition Tolerance) and PACELC Theorem.
* **Routing:** Consistent Hashing (crucial for distributing data evenly across shards).

## Chunk 12: Advanced Paradigms (NoSQL, Analytics & AI)
* **NoSQL Categories:** Key-Value (Redis), Document (MongoDB), Column-Family (Cassandra), Graph (Neo4j).
* **BASE Properties:** Basically Available, Soft state, Eventual consistency.
* **Analytics:** OLTP (Online Transaction Processing) vs. OLAP (Online Analytical Processing). Star and Snowflake schemas for data warehousing.
* **Modern Data Architecture:** Event Sourcing and CQRS (Command Query Responsibility Segregation).
* **Vector Databases:** Pinecone, Milvus, or pgvector. Understanding how embeddings are stored and queried using similarity search (e.g., Cosine Similarity, K-Nearest Neighbors) is highly relevant for integrating Artificial Intelligence features.
