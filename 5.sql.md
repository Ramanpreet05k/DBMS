Chunk 4: SQL Programming Masterclass
* Basic Queries: SELECT, WHERE, GROUP BY, HAVING, ORDER BY.
* Operators: Arithmetic, Logical, Comparison, BETWEEN, IN, LIKE, IS NULL.
* Aggregate Functions: SUM, AVG, MIN, MAX, COUNT.
* Joins & Set Operations: INNER, LEFT, RIGHT, FULL OUTER, CROSS, SELF JOIN. UNION, UNION ALL, INTERSECT, EXCEPT.
* Subqueries: Nested, Correlated, and Inline Views.
* Advanced SQL:
    * Common Table Expressions (CTEs) and Recursive CTEs.
    * Window/Analytic Functions (ROW_NUMBER, RANK, DENSE_RANK, LEAD, LAG, NTILE).
* Database Objects:
    * Views (Simple vs. Complex).
    * Materialized Views: (Crucial for building fast dashboards in analytics platforms).
    * Triggers (Row-level vs. Statement-level).
    * Stored Procedures, User-Defined Functions (UDFs), and Cursors.
